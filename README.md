# Phytotox_Ag_Ferrite
Python pipeline for Ag@CoFe2O4 NP phytotoxicity in wheat. Processes ICP-OES data with LOD corrections, finds NOAEC/LOAEC via Dunnett's test, and computes IC50 via LL.3 log-logistic models. Uses Z-score standardization and PCA biplots to decode links between metal bioaccumulation, pigments, and antioxidant enzymes (CAT, APX, GPX, SOD).
